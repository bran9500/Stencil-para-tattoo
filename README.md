# Capas Stencil

App Android para dividir un diseño de tatuaje por tonos (2 a 6 capas) y verlo capa por capa: de lo más claro a lo más oscuro.

- Abrir cualquier imagen (o compartirla a la app desde la galería)
- Quitar el fondo automáticamente y tocar huecos para borrarlos
- Ajustar número de tonos, punto de piel y cortes entre capas
- Ver: ir sumando / solo esta capa; real, gris plano, guía (rosado = sin tinta), original; fantasma y contorno
- Guardar en la galería (Pictures/Capas): capas transparentes y guías

La APK se compila sola con GitHub Actions en cada push a `main` y queda en **Releases**.
